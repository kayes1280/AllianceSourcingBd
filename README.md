# Alliance Sourcing BD

## Overview

Alliance Sourcing BD is a company website for an apparel sourcing and manufacturing business. It presents the company's services and capabilities to international brands, including buying house services, product expertise, factory and machinery support, and global partnerships.

The site includes dedicated pages for the company overview, buying house services, factory and machinery, and global partners, alongside a home page that introduces the business and its sourcing process.

## Frontend stack

- **React 19** for building the user interface
- **TypeScript** for typed components and application code
- **React Router 7** for routing and page layouts
- **Tailwind CSS 4** for responsive styling
- **Vite** for development and frontend builds

## Project purpose

The project provides a clear online overview of Alliance Sourcing BD and helps prospective clients understand its apparel sourcing, product development, production follow-up, quality inspection, and manufacturing capabilities.
