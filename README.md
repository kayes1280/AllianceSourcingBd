# Alliance Sourcing BD

## Overview

Alliance Sourcing BD is a responsive company website concept for an apparel sourcing and manufacturing business. It introduces the company, explains its buying house services and factory capabilities, and presents its global partners.

The site includes these pages:

- **Home** (`/`) — introduction to the business
- **About** (`/about`) — company overview
- **Buying House** (`/buying-house`) — sourcing and product services
- **Factory** (`/factory`) — factory and machinery capabilities
- **Partners** (`/partners`) — global partnerships

## Tech stack

- **React 19** — user interface
- **TypeScript** — typed application code
- **React Router 7** — routing and server rendering
- **Tailwind CSS 4** — styling
- **Vite 8** — development server and build tooling
- **Lucide React** and **React Icons** — icons

## Purpose

This project was built for learning and practice. It provides a hands-on way to explore building a multi-page website with React, TypeScript, React Router, and Tailwind CSS. The apparel sourcing business is the subject of the site; the project itself is a learning exercise.

## Getting started

Make sure Node.js and npm are installed, then run:

```bash
npm install
npm run dev
```

Use the local URL printed by Vite to open the site in your browser.

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run start` — serve the production build
- `npm run typecheck` — generate route types and run TypeScript checks
